# Panel d'Administration - Moulin Gouré

Le panel d'administration permet de gérer facilement le contenu du site web du Moulin Gouré sans avoir à modifier directement les fichiers HTML.

## Fonctionnalités

### Configuration générale
- Modification du nom du site
- Mise à jour de la description
- Paramétrage des informations de contact
- Personnalisation des couleurs du site

### Réseaux sociaux
- Liens vers Facebook
- Liens vers Instagram
- Liens vers WhatsApp

### Fonctionnalités
- Activation/désactivation des différentes sections du site
- Gestion des fonctionnalités avancées

## Utilisation

1. Ouvrez `admin/index.html` dans votre navigateur
2. Modifiez les paramètres selon vos besoins
3. Cliquez sur "Sauvegarder" pour enregistrer les modifications
4. Les modifications sont automatiquement sauvegardées dans le navigateur (localStorage)

## Sauvegarde

Les configurations sont stockées dans le navigateur via `localStorage`. Pour une sauvegarde permanente :
1. Copiez le contenu du fichier `config.json`
2. Sauvegardez-le dans un emplacement sûr
3. Restaurez-le si nécessaire

## Compatibilité

Le panel d'administration fonctionne sur tous les navigateurs modernes :
- Chrome 60+
- Firefox 55+
- Safari 10+
- Edge 16+

## Sécurité

- Aucune donnée sensible n'est envoyée au serveur
- Les configurations sont stockées localement dans le navigateur
- Le panel est entièrement statique (pas de backend requis)
