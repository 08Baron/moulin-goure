# Site Web du Moulin Gouré

Site web complet pour le Moulin Gouré, un patrimoine en restauration à Louresse-Rochemenier.

## 🏛️ Description

Le Moulin Gouré est un moulin patrimonial en cours de restauration. Ce site web a pour objectif de présenter l'histoire du moulin, les travaux de restauration en cours, les visites disponibles et de permettre aux visiteurs de soutenir financièrement la conservation de ce patrimoine.

## 🚀 Fonctionnalités

### Sections principales
- **Accueil** : Héros avec accroche, aperçu de la frise, vlog, prochaine visite et cagnotte
- **Historique** : Frise chronologique interactive des événements majeurs
- **Vlog** : Actualités et témoignages avec pagination et réglage de taille du texte
- **Galerie photo** : Grille de photos triées par catégories avec vue agrandie
- **Visites** : Liste des dates disponibles avec réservation et itinéraire Google Maps
- **Contact** : Formulaire fonctionnel et informations pratiques
- **Mentions légales** : Page dédiée aux mentions légales

### Fonctionnalités avancées
- **Animations CSS** : Transitions fluides et effets visuels
- **Design responsive** : Adapté à tous les appareils
- **Widgets flottants** : Rappels de visite et relances discrètes
- **Cagnotte synchronisée** : Montant mis à jour automatiquement (simulation)
- **Traduction automatique** : Sélecteur de langue
- **Admin panel** : Interface de gestion du contenu

## 🛠️ Technologies utilisées

- **HTML5** : Structure et sémantique des pages
- **CSS3** : Styles, animations et responsive design
- **JavaScript ES6** : Fonctionnalités interactives et dynamiques
- **Responsive Design** : Adaptation à tous les écrans
- **Local Storage** : Sauvegarde des configurations administratives

## 🎨 Design et UX

- **Palette de couleurs** : Dégradés bleus et violets pour un style moderne
- **Typographie** : Playfair Display pour les titres, Roboto pour le corps de texte
- **Animations** : Transitions fluides, effets hover, animations au scroll
- **Responsive** : Adaptation complète pour mobile, tablette et desktop

## 🖥️ Installation

### Prérequis
- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Aucune installation nécessaire - site statique

### Utilisation
1. Téléchargez ou clonez le projet
2. Ouvrez `index.html` dans votre navigateur
3. Accédez au panel d'administration via `/admin/index.html`

## 🛠️ Panel d'Administration

Le panel d'administration permet de :
- Modifier les textes et informations du site
- Configurer les couleurs du site
- Activer/désactiver les fonctionnalités
- Gérer les réseaux sociaux
- Sauvegarder les configurations dans le navigateur

## 📱 Responsive Design

Le site est entièrement responsive et s'adapte à :
- Mobiles (petits écrans)
- Tablets (moyens écrans)  
- Desktops (grands écrans)

## 🔧 Personnalisation

### Couleurs
Les couleurs peuvent être modifiées dans le panel d'administration ou directement dans `css/style.css` :

```css
/* Dégradés de couleur */
background: linear-gradient(135deg, #6a11cb 0%, #2575fc 100%);
```

### Contenu
Tout le contenu peut être modifié via le panel d'administration ou directement dans les fichiers HTML.
